# ChefOST organization handbook

Shared project goals, research notes and contribution guidance for ChefOST's work on tracking object states in cooking videos.

- [Organization guide](profile/README.md): choose a repository and find active work.
- [Project goals](docs/PaperNotes.md#project-goals): scope and priorities.
- [Paper notes](docs/PaperNotes.md): cited methods, results, limitations and ChefOST adaptations.
- [Contribution guide](CONTRIBUTING.md): branch naming, pull requests and documentation conventions.

## For coding agents

Read the project goals, choose the relevant repository using the organization guide, then read that repository's README and applicable `AGENTS.md`. Read only the paper entries and detailed docs relevant to the task. Distinguish published results from ChefOST proposals and experiments.

## Maintaining these docs

Keep the organization homepage in [profile/README.md](profile/README.md) and research context in [docs/PaperNotes.md](docs/PaperNotes.md). Link to these sources instead of duplicating them. Repository-specific instructions remain in each repository; agents do not automatically inherit this handbook.
